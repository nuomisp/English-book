# 原生验证版设计与验证记录

## 范围

用户目标：魅族 21（骁龙 8 Gen 3、8GB 实体内存、Android 16）原生安卓应用，从初中英语基础学习到四级，每天两小时、前期词汇优先。Gemini 风格的简洁对话首页和原创傲娇角色，独立背词页与真实学习进度共用数据库。中转 API 由用户填写；服务端部署待 SSH 与域名信息。

原生 UI 使用 Jetpack Compose，没有 WebView、网页资源或 JavaScript 运行时。角色头像和图标为本项目绘制的矢量图。学习材料为起步验证内容（100词、3篇短文、40句听写），尚非完整备考课程。

## 上下文与学习记录

- SQLite 是词汇进度、答题、时长和聊天的唯一数据源。到期复习优先，每天最多安排20个新词。
- 显示的“长期巩固”需要复习间隔达到21天且连续正确至少3次；一次认识不算掌握。
- 发给 AI 的对话最多16条、总计约14,000字符；单条最多4,000字符，附不超过6,000字符的学习汇总和文字记忆。
- 每12条聊天记录尝试整理一次摘要；手动编辑或删除优先于并行生成的摘要。后台分工可指定教学/记忆模型，默认使用同一模型。
- 普通聊天不会自动修改学习成绩或执行 AI 声称的操作。学习计数来自实际点击与答题，AI 只是解释这些记录。
- 系统时间、模型回答均可能不准确；用户可以查看与编辑文字记忆。备份包含聊天文字，不包含接口密钥。

## 语音与通知

目前支持 Android 系统英语 TTS 及 OpenAI 兼容的 MP3语音 API，后者最多缓存64MiB。MOSS尚未集成，不做性能保证。长文本需分段朗读。

本地通知使用 WorkManager 而非精确闹钟，计划随机4次和21:30回顾，所有提示在09:00–22:00窗口内。随机通知间至少90分钟，避开晚间回顾前后30分钟；超时、目标完成后不补发。

可选服务器使用单用户Bearer认证、SQLite持久化和过期策略；手机每约15分钟同步，不属于厂商推送。杀进程/强行停止/后台省电仍可能影响到达。服务端需要单独配置AI密钥，手机不上传密钥。

## 构建与签名

GitHub Actions 在开发分支运行单元测试、lint、debug APK、原生模拟器测试与截图。发布签名通过三个仓库 Secrets 配置，非PR构建生成 `EnglishBook-signed-apk`。签名私钥不在版本库中。签名备份保存在本机 `.local/signing`，密码由当前Windows用户DPAPI保护；应由仓库所有者另行安全备份。

版本号0.1.0，versionCode随Actions运行编号递增。固定私钥签署的版本可覆盖更新，debug APK与release APK的签名不同，请优先安装signed版本。
